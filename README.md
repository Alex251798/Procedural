# Procedural Engine

High-performance procedural algorithms and data structures library for JavaScript.

## Modules
- **Math & Linear Algebra**: Vectors, matrices, geometric computation, number theory.
- **Data Structures**: BST, LRU Cache, Heap / Priority Queue, Trie, Disjoint Set Union.
- **Algorithms**: QuickSort, Dijkstra graph traversal, 0-1 Knapsack, binary searching.
- **Strings**: Levenshtein distance, slugification, template interpolation.
- **Async Utilities**: Task concurrency pools, exponential backoff with jitter.
- **Cryptography**: FNV-1a checksums, Adler32, deterministic PRNG.
